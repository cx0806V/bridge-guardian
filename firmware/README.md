# 桥体卫士 —— ESP32 采集终端（硬件闭环）

本文档说明 ESP32 + HX711 采集终端的接线、烧录、标定，以及与 Flask 后端的串口对接。

> 用途声明：本终端用于**缩尺桥梁模型的受载变化模拟**，输出为相对应变（με），
> 并非经工程级标定的真实桥梁应变监测设备。

## 1. 硬件清单

| 器件 | 数量 | 说明 |
|---|---|---|
| ESP32 开发板（CP2102） | 1 | 主控，USB 串口直连电脑 |
| HX711 模块 | 1 | 24 位 ADC 称重/压力采集 |
| 称重/压力传感器 | 1 | 200g 条形 或 1kg 圆形（四线制） |
| 0.96" OLED（SSD1306，I2C） | 1 | 本地显示当前值/状态 |
| 有源蜂鸣器 | 1 | 超限本地声光报警 |
| 红色/绿色 LED + 限流电阻 | 各 1 | 状态指示 |
| 面包板 + 电源 + Type-C 线 | — | 供电与连线 |

## 2. 接线表（对应 `main.py` 顶部引脚常量）

| 信号 | ESP32 GPIO | 说明 |
|---|---|---|
| HX711 DT | 21 | 数据线 |
| HX711 SCK | 22 | 时钟线 |
| HX711 VCC / GND | 3V3 / GND | 供电 |
| 传感器 E+/E-/A+/A- | HX711 对应端 | 四线制：E+/E- 激励，A+/A- 信号 |
| OLED SDA / SCL | 4 / 5 | I2C |
| OLED VCC / GND | 3V3 / GND | 供电 |
| 有源蜂鸣器 + | 26 | 高电平响 |
| 红色 LED（经限流电阻） | 27 | 报警指示 |
| 绿色 LED（经限流电阻） | 14 | 正常指示 |

> 引脚可在 `main.py` 顶部常量中按实际接线修改。

## 3. 烧录步骤

1. **刷入 MicroPython 固件**（一次即可）：
   ```bash
   # 下载 ESP32 通用固件（如 esp32-20240105-v1.22.0.bin）
   esptool.py --port COM3 erase_flash
   esptool.py --port COM3 --baud 460800 write_flash -z 0x1000 esp32-xxx.bin
   ```
2. **上传代码**（用 Thonny 或 ampy）：
   - 将 `firmware/main.py` 上传为 `main.py`（开机自动运行）
   - 上传 MicroPython 官方 `ssd1306.py` 驱动（用于 OLED，未接 OLED 可跳过）
3. 复位 ESP32，OLED 应显示 `Bridge Guardian`，串口监视器每 1 秒输出一行 JSON。

## 4. 标定流程

HX711 输出为原始 24 位读数，需标定 `OFFSET`（零点）与 `SCALE`（比例系数）：

1. **零点标定**：传感器空载（无受力），在串口监视器观察原始读数，取稳定值填入 `OFFSET`。
   （可在固件临时加 `print(hx711_read())` 观察原始值。）
2. **比例标定**：施加已知载荷（如 100g 砝码），记录读数变化量：
   ```
   SCALE = (加载读数 - 空载读数) / 已知载荷对应的应变值
   ```
3. 将 `OFFSET`、`SCALE` 填入 `main.py`，重新上传。

> 应变值与载荷的换算关系由缩尺桥梁模型的力学假设决定，答辩时说明口径为
> 「受载变化模拟」，标定仅为让数值随载荷单调、稳定变化。

## 5. 与 Flask 串口对接

1. 修改 `.env`（或系统环境变量）：
   ```
   DATA_SOURCE=serial
   SERIAL_PORT=COM3
   SERIAL_BAUD=115200
   ```
2. 安装依赖并启动：
   ```bash
   pip install -r requirements.txt
   python app.py
   ```
3. 大屏「设备健康度」应显示「设备在线」+ 心跳时间；拔掉 USB 或断电后显示「设备离线」，
   系统不会伪造在线状态或数据。

## 6. 数据协议

固件每秒经串口输出一行 JSON（与 `datasource.SerialSource` 解析一致）：
```json
{"v": 123.45, "id": "ESP32-01"}
```
- `v`：相对应变值（με）
- `id`：设备标识（可选，缺省为 ESP32）
