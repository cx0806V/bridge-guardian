# 桥体卫士 —— 现场启动手册

面向校赛现场的部署与演示操作流程，含「演示模式（模拟）」与「真实硬件模式」两种。

## 一、赛前准备清单

- [ ] 电脑（Windows，已装 Python 3 与 pip）
- [ ] 项目代码（含 `requirements.txt`、`.env.example`）
- [ ] 硬件：ESP32 + HX711 + 称重/压力传感器 + 0.96 OLED + 有源蜂鸣器 + 红绿 LED + 面包板 + Type-C
- [ ] 缩尺桥梁模型（传感器已固定）
- [ ] 备用 Type-C 线、面包板跳线

## 二、演示模式（模拟数据源，无硬件也能完整演示）

1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
2. （可选）导入历史数据：
   ```bash
   python migrate.py --dry-run   # 先预览
   python migrate.py             # 导入旧 CSV 到 SQLite
   ```
3. 启动服务：
   ```bash
   python app.py
   ```
4. 浏览器访问 `http://127.0.0.1:5000`，登录 `admin / 123456`。
5. 演示流程见 `docs/答辩材料.md` 的「演示流程」。

## 三、真实硬件模式（ESP32 + HX711）

### 步骤 1：接线（详见 `firmware/README.md`）

按接线表连接 HX711、传感器、OLED、蜂鸣器、LED 到 ESP32。

### 步骤 2：烧录固件

1. 刷入 MicroPython 固件（esptool）。
2. 上传 `firmware/main.py`（与 `ssd1306.py`）到 ESP32。
3. 完成标定（零点 `OFFSET` 与系数 `SCALE`）。

### 步骤 3：配置并启动

`.env` 设置：
```
DATA_SOURCE=serial
SERIAL_PORT=COM3        # 按设备管理器实际端口
SERIAL_BAUD=115200
```

```bash
python app.py
```

### 步骤 4：验证

- 大屏「设备健康度」显示「设备在线」+ 最近心跳持续刷新。
- 对模型施加载荷，应变值上升、超过阈值触发分级报警、蜂鸣器与红 LED 亮起。
- 拔掉 USB 或给 ESP32 断电，大屏如实显示「设备离线」，不伪造数据。

## 四、故障排查

| 现象 | 排查 |
|---|---|
| 大屏显示「设备离线」 | 检查 USB 连接、`SERIAL_PORT` 是否正确、ESP32 是否在运行 |
| 端口被占用 | 改 `app.py` 中端口，或结束占用进程 |
| 登录失败 | 核对 `.env` 中 `APP_USERNAME` / `APP_PASSWORD` |
| 历史数据为空 | 先 `python migrate.py` 导入旧 CSV |
| 串口乱码/无数据 | 核对波特率 115200、固件是否输出 JSON |

## 五、现场稳定性要点

- 优先使用**串口 USB 直连**，不依赖现场网络，最稳定。
- 演示前用模拟模式完整跑一遍流程，确认无异常。
- 现场准备一份纯模拟模式兜底：若硬件突发故障，可立即切换 `DATA_SOURCE=sim` 继续演示。
