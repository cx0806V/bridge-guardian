> 打印此页带到现场，逐项打勾。覆盖：硬件接线 / 标定 / 真实模式 / 模拟模式 / 故障兜底。

## 1. 硬件接线（对照 firmware/README.md 接线表）

- [ ] ESP32 通过 USB（Type-C / CH340）连电脑，设备管理器出现 `USB-SERIAL CH340 (COMx)`（记下端口号：____）
- [ ] HX711：DT→GPIO21，SCK→GPIO22，VCC→3V3，GND→GND
- [ ] 传感器四线：E+/E-/A+/A- 对应接 HX711
- [ ] OLED：SDA→GPIO4，SCL→GPIO5（未接可跳过）
- [ ] 蜂鸣器模块→GPIO26，红灯模块→GPIO27，绿灯模块→GPIO14（LED 模块自带限流电阻，不外接）
- [ ] 上电后 ESP32 绿灯亮、OLED 显示 "Bridge Guardian"、串口监视器每 1 秒输出一行 JSON

## 2. 标定（对照 docs/标定与实测记录模板.md）

- [ ] 空载稳定 ≥5 分钟，记录 OFFSET（去皮基准）
- [ ] 准备 ≥3 档已知砝码/载荷（如 50g/100g/150g/200g）
- [ ] 每档加载后连续记录 ≥5 次 raw_value（间隔 1 秒）
- [ ] 线性拟合得 SCALE，R² ≥ 0.95
- [ ] 将 OFFSET/SCALE 写入 main.py，CALIBRATION_VERSION +1，重新上传
- [ ] 复测：读数随载荷单调、稳定变化

## 3. 真实模式（DATA_SOURCE=serial）

- [ ] `.env`：`DATA_SOURCE=serial`，`SERIAL_PORT=<实际端口>`，`SERIAL_BAUD=115200`
- [ ] `python app.py` 启动，浏览器登录 admin（用 `.env` 里的账号密码）
- [ ] 大屏「设备健康度」显示「设备在线」+ 最近心跳持续刷新
- [ ] 顶部徽章显示「数据源：串口(真实)」，**无**「模拟演示」水印
- [ ] 施加载荷：指标上升、超阈值触发分级报警、蜂鸣器+红灯亮
- [ ] 拔 USB：大屏如实「设备离线」+ 触发「设备离线」严重报警（不沿用旧值）
- [ ] 重新上电：自动记录「设备恢复」

## 4. 模拟模式（DATA_SOURCE=sim，兜底用）

- [ ] `.env`：`DATA_SOURCE=sim`，重启服务
- [ ] 大屏出现「模拟演示 · 非真实硬件数据」水印 + 场景切换面板
- [ ] 依次点六场景，验证：正常→预警→报警→严重→离线→恢复，均一键复现
- [ ] 场景切换后设置页「最近变更记录」能看到审计

## 5. 故障兜底

- [ ] 硬件正常 → 走路径 A（真实模式完整演示）
- [ ] 硬件故障 → 立即切路径 B：改 `DATA_SOURCE=sim` 重启，口头说明「切模拟模式继续」，不硬撑、不伪装
- [ ] 演练一遍「拔线 → 离线 → 恢复」和「乱码 → 丢弃 → 恢复」两个故障场景
