# 桥体卫士 —— 收货核对 + 到货流程卡（打印这页）

> 用途：**A4 打印带到实验室/现场**，收货对件、到货当天 70 分钟照做、现场 15 分钟照跑。

## A. 收货对件（9 件，逐件打勾）

| ✔ | 件 | 收货验收要点（不合格就当场退换） |
|---|---|---|
| ☐ | Type-C 数据线 1 m | **必须是数据线**：插上电脑要能出 COM 口；纯充电线插上什么都不出 |
| ☐ | MB102 面包板套装 | 830 孔 + 65 条跳线齐；**电源模块本次不用** |
| ☐ | LED 模块 绿 ×1 | 针脚丝印 `- + S` 或 `S + -`（看清再插，模块自带电阻） |
| ☐ | LED 模块 红 ×1 | 同上 |
| ☐ | 200 g 砝码套装 | 清点克重（常见 200/100/50/20/10/5 g），缺档会影响标定分档 |
| ☐ | 1 KG 圆称架散件 | **三件齐**：1 kg 四线圆称 + HX711 模块 + 支架；圆称引出线无破皮、无断芯 |
| ☐ | 有源蜂鸣器模块 ×2 | 标注"高电平触发"；2 只都留（1 只备用，防发错极性版本） |
| ☐ | OLED 0.96" 4 针 | 丝印 `GND VCC SCL SDA`，1306/SSD1306 兼容 |
| ☐ | ESP32 开发板 Type-C | **CH340**（不是 CP2102）；板上丝印有 `GPIO21/22/26/27/14/4/5`、`3V3`、`GND` |

**到货即做的一件事**：只插开发板（不接任何模块）→ 设备管理器出现 `USB-SERIAL CH340 (COMx)` 才算过；有黄色感叹号就先装 CH341SER 驱动。

## B. 到货当天（约 70 分钟，按分钟走）

| 分钟 | 动作 | 命令 / 判据 |
|---|---|---|
| 0–10 | 装 CH340 驱动、认端口；装工具 | `python -m serial.tools.list_ports -v` → 看到 COMx；`python -m pip install esptool mpremote` |
| 10–25 | **断电**接线 + 6 条自查（DT21 / SCK22 / 蜂鸣器26 / 红27 / 绿14 / SDA4 / SCL5，全部共地，HX711 走 3V3） | 万用表通断档确认共地；接线表见主文档 3.1 |
| 25–28 | 上电、验模块极性（S 碰 3V3 看亮不亮） | 高电平亮/响 = 与固件一致 ✔；反了换模块 |
| 28–33 | 刷 MicroPython（按住 BOOT→点 EN→松 BOOT） | `erase-flash` → `write-flash 0x1000 ESP32_GENERIC-20260824-v1.29.0.bin` → `Hash of data verified.` |
| 33–36 | 上传固件 | `mpremote connect COMx fs cp firmware/main.py :main.py`；`ssd1306.py` 用 `.workbuddy/firmware-cache/` 里那份 |
| 36–39 | 空载自检 | `python scripts\calib_log.py --port COMx --tag 空载 --count 5` → 有 raw_value、`sensor_state` 由 uncalibrated 待标定 |
| 39–60 | 标定：0 / 50 / 100 / 150 / 200 g，每档 5 次 | `--tag L4_200g --count 5 --csv .workbuddy\calib\calib.csv`；拟合 **R² ≥ 0.95** |
| 60–62 | 回填 `OFFSET/SCALE`，`CALIBRATION_VERSION +1`，重传 | 复测 `sensor_state=ok`、`calibration_version=1` |
| 62–70 | 接后端验收 | `.env`：`DATA_SOURCE=serial` / `SERIAL_PORT=COMx` / `SERIAL_BAUD=115200` → `python app.py` → `/device` 显示**设备在线** + 心跳，顶栏**无**「模拟演示」徽章 |

**当场必验两条诚实边界**：拔 USB → 约 5 秒内转「设备离线」+ 严重报警（不沿用旧值）；插回 → 自动记录「设备恢复」。

## C. 现场（约 15 分钟）

| 分钟 | 动作 |
|---|---|
| 0–5 | 插线复核（对照 A 段表格逐根看一眼）+ 上电看 OLED 与绿灯 |
| 5–8 | 启动服务、登录、确认「设备在线」+ 无模拟水印 |
| 8–13 | 演示四级：**100 g 安全 → 125 g 预警 → 135 g 报警 → 150 g 严重**；拔线演示离线与恢复 |
| 13–15 | 兜底确认：`.env` 改 `DATA_SOURCE=sim` 能立刻接管（不硬撑、不伪装） |

> 答辩要点：**每次放/拿砝码都会触发「变化率突变」报警**，这是可解释规则的设计结果（|Δ|≥10 报警、≥20 严重），要主动说明，别说成 bug。

## D. 卡点急救（三条最常踩）

| 症状 | 一步定位 | 处置 |
|---|---|---|
| `no ports found` | 线是不是数据线？设备管理器有没有 CH340？ | 换线 → 装 CH341SER → 换 USB 口（不用 Hub） |
| `Failed to connect`（esptool） | 没进下载模式 / 端口写错 | 按住 BOOT → 点 EN → 松 BOOT；核对 `--port` |
| 串口打不开 / 读数不动 | 端口被占用（Thonny、监视器、app.py 三选一） | 一次只留一个程序；`DT/SCK` 复查到 21/22 |

**关键数字**：阈值 120 → 预警 >120、报警 ≥132、严重 ≥144 ｜ 离线判据：连续 10 次读超时（≈5 s）｜ 采样节奏：≈1.7 s/行（8 次 HX711 滤波 + 1 s 周期，现场以实测为准）｜ 固件 sha256 前 16 位 `e67ad6015a0a504c`。
